# Ciclo de Vida

```text
Detectada
→ Em análise
→ Dor confirmada
→ Comprador identificado
→ Teste planejado
→ Em validação
→ Interesse confirmado
→ Preço testado
→ MVP aprovado
→ Em construção
→ Primeira receita
→ Escala
```

Estados laterais: Pausada e Descartada.

## Regras

- avanço exige evidência observável;
- comprador não é inferido como fato;
- preço só é “testado” após oferta real;
- primeira receita exige evento financeiro registrado;
- descarte preserva motivo e aprendizado;
- retorno a uma etapa anterior é permitido quando nova evidência contradiz a hipótese.
