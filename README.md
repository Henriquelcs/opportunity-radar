# Opportunity Radar

Engine modular para identificar problemas reais
e oportunidades de negócio usando dados públicos.

## Estrutura inicial

- `src/config`: configurações
- `src/collectors`: coleta de dados
- `src/processors`: tratamento e classificação
- `src/reports`: geração de resultados
- `tests`: testes automatizados
- `data`: arquivos gerados
